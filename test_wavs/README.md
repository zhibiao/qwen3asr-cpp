# test_wavs

端到端回归音频集，来源于 <https://qwen.ai/blog?id=qwen3asr>。

- `transcript.txt`：每行 `文件名 参考转写`。
- 15 条 WAV，覆盖中文、英文、粤语、阿拉伯语、德语、西班牙语、法语、俄语、日语和中英混合。
- 其中 10 条为 16 kHz，5 条为 44.1 kHz。
- 44.1 kHz 文件由 `wav_reader` 在测试/运行时自动重采样到 16 kHz，
  不再需要预转换夹具。

参考转写是人工文本，不保证与模型输出逐字一致；
端到端比较请使用归一化后的 CER/WER，而不是字符串完全相等。
